westpa.work\_managers.mpi package
==================================

The MPI work manager is not functional by default. To use it, install ``mpi4py`` with pip using the ``[mpi]`` flag with westpa (e.g. ``python -m pip install westpa[mpi]``).
You may also install ``mpi4py`` with conda using ``conda install -c conda-forge mpi4py``. You will also need an existing installation of MPI (e.g. ``openmpi``) on your system.
